# 统一工作台界面

Vantage 只有一个登录后的工作台。左侧主导航依次进入 Agent、总览、监控、报告和告警；组织与账户入口始终在相同位置。Agent 对话与业务页面共用账户、组织、主题和登录状态，不需要切换界面版本。

| 区域 | 桌面端 | 窄屏端 |
| --- | --- | --- |
| 主导航 | 左侧图标栏，悬停显示名称 | 底部图标与名称 |
| 次级区域 | Agent 显示对话列表；业务页面显示模块列表 | 对话列表横向滚动；业务列表按需展开 |
| 内容区 | 对话或业务页面，独立滚动 | 保留固定导航与可见的输入区 |

`/app` 是 Agent 对话入口，`/dashboard`、`/watchlist`、`/reports`、`/alerts` 是同一工作台中的业务地址。旧 `/agent` 自动跳转到 `/app`。Demo 继续使用真实界面和独立演示组织，写入、模型、搜索与通知操作由服务端限制。

界面状态需覆盖加载、空列表、运行中、失败、审批等待、已完成及无权限。导航和对话操作提供可读标签与键盘焦点；用户选择减少动态效果时停用非必要滚动动画。配色沿用项目的黑、白、米色变量，暗色主题不额外复制页面结构。
