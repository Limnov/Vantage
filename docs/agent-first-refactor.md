# Agent-first 双模式重构

2026-09-05

## 产品契约

默认核心流程为：输入目标 → Agent 查找真实业务对象 → 执行受限工具 → 展示数据库结果或情报证据 → 连续追问。只有一个 Agent，无模板角色切换。原六个分析工具扩展为 21 个业务工具。顶部按钮允许在 Agent-first 与原始经典管理界面之间切换，两个界面共用认证、组织上下文、API 和数据库。

所有执行结果必须保留原始工具输入和输出，并将失败明确展示；创建监控会显示实际 ID 和启用状态。飞书审批显示报告 ID 与建议原因，批准与拒绝保持独立交互。空列表、运行中、失败、停止、权限不足和无组织上下文均有界面反馈。

界面采用黑、白、米色系统，右侧对话、左侧历史。移动端将历史收为横向条；支持暗色、键盘提交、中文输入法组合状态和 reduced-motion。经典版在窄屏收起侧栏，以浮层方式展开，顶部保留组织、模式、主题和用户入口。

## 行为变化

1. Agent-first 为默认入口；11 个旧业务页面及旧导航作为按需加载的经典版保留。界面模式写入 `localStorage`，刷新后恢复，切换时同步导航到 `/` 或 `/dashboard`。
2. 新增监控、报告列表、告警、路由、组织概况和成员查询工具。新增写工具每次重新校验数据库权限，阻止跨组织 ID 和模型参数越权。
3. 业务操作与情报研究分开保存。操作记录可作为下一轮上下文，不依赖 report_id 才能续接。
4. 通知建议必须来自成功执行的工具；最终模型 JSON 不能直接指定任意通知对象。支持当前任务生成的报告，以及已有报告。
5. 取消状态在同一模型回复中的每个工具前检查。SSE 在关闭时清理推送与心跳定时器。
6. 修复调度器忽略 cron 的行为，使用 cron-parser 判断到期时间。SQLite 时间按 UTC 解读，cron 使用服务器时区。
7. 修复登录状态 hydrate 后未更新订阅快照、刷新页面误回登录页的问题，以及注册后尚未设置认证就调用 me 的问题。
8. 经典版、旧页面样式和图表依赖拆入独立分包，仅在切换到经典版时加载。Windows 启动脚本和根目录 npm 命令使用 SQLite 流程。
9. Agent 任务先写入 `agent_jobs`，Worker 通过原子更新领取并维护租约。无写副作用的失联任务自动恢复；已经成功执行写工具的任务失败关闭，防止重复写入。
10. 根 `package.json` 提供唯一版本号，Vite 构建、后端健康接口、侧栏和关于页共同读取 `3.0.0`。

## 验证边界

- 后端回归使用临时数据库：监控生命周期、参数验证、viewer 拒绝写入、成员权限变化即时生效、跨组织拒绝、告警处理、通知路由、业务结果持久化语义、取消、模型伪造通知目标以及 cron 调度。
- 浏览器使用真实认证、REST、队列、Runner、Registry 和 SQLite；模型与外部通知采用固定夹具。测试包含 Agent-first/经典版双向切换、模式刷新恢复、经典 Dashboard、创建、追问、批准发送一次、组织切换、两套移动布局和配置表单。
- 真实模型只读套件使用临时数据库，分别只暴露 `get_workspace`、`list_watchlists`、`list_alerts`，输出工具选择率、延迟和 Token。不会自动启用真实监控或向真实飞书发送消息。
- MCP 继续共用工具契约。新增写工具更新 readOnly、destructive 和 idempotent 提示，同时由服务端实际权限约束。

## 保留的边界

凭据配置使用独立安全表单，不能要求用户将 API Key、密码或 Webhook 写入对话。组织和成员写管理仍通过既有 REST API 完成；Agent 只读成员。没有任意 SQL、Shell、MCP 审批发送能力。

定时监控沿用组织已配置的通知机制；创建默认为暂停。任务取消不回滚已经完成的业务操作，也不强制中断所有上游请求。SQLite 队列支持共享同一数据库文件的多个 Worker；跨主机部署仍需要外部队列与统一限流。写工具成功后发生进程崩溃时，任务失败关闭并保留轨迹，不会自动重复副作用。

## 本次验收结果

- `npm run check` 通过：41 项后端测试全部通过，TypeScript 与 Vite 生产构建完成；6 场景离线质量套件通过率 100%。
- 经典入口由约 1.96 MB 降至约 114 KB，Dashboard 由约 1.48 MB 降至约 23 KB；页面按需加载且无超过 500 KB 的经典页面分包。
- `npm run test:ui` 覆盖 15 类浏览器检查，包含经典版手机布局、重复批准幂等性、SSE 终止与无页面运行错误。
- `npm run test:live` 使用 `openrouter/free` 执行 3 个只读业务场景，工具选择率 100%，平均延迟 16,976 ms，总计 8,586 Token。
- 外部通知在浏览器测试中使用固定夹具，没有向真实飞书发送消息。完整真实市场搜索链路仍需在允许外部搜索成本时单独评测。
