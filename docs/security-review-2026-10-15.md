# 2026-10-15 开源安全维护记录

## 结论与范围

仓库此前已公开，本次是在原 MIT 仓库上修补并明确自托管边界，不是首次公开。检查从 `main` 的 `c6125a2` 开始，历史范围包含远端展示页分支及三个归档标签，共 68 个可达提交；没有重写、删除提交或公开生产数据。

检查覆盖源码与配置、可达 Git 历史、Server / Web / Desktop 锁文件，并复核认证会话、多组织权限、共享账号、敏感配置 DTO、Agent/MCP 工具权限、网页抓取与人工通知审批。它是一次源码与离线验证，不是独立渗透测试，也不证明没有未知漏洞。

## 公共服务下线

- `vantage-pi.service` 已停止，开机自启已禁用，原监听端口不再提供业务。
- Caddy 所有路径改为 HTTP 410，附带 `Cache-Control: no-store, max-age=0` 和 `X-Robots-Tag: noindex, nofollow`。独立 Tunnel 只转发下线响应，不转发应用。
- 公网 `/`、`/login`、`/app`、`/demo`、`/evidence`、`/api/auth/login`、`/health` 与 Logo 路径均实测返回 410。
- 生产 SQLite 已使用在线备份保留在主机私有目录；61 条未撤销会话已撤销，1 个外部试用账号已停用。旧测试账号不再提供公网访问。
- 数据库、私有环境配置、备份和旧静态产物未上传 GitHub。共享主机上的其他服务未停止。

## 秘密与源码边界

Gitleaks 8.30.1 扫描当前目录和全部可达 Git 历史。原始 7 个历史命中均为离线测试的 3 种固定假密钥；逐项核对后，配置只放行这三个精确值，且仅在指定的三个测试文件生效。其他测试文件和其他值仍受扫描约束。额外的未放行假密钥探针能使扫描失败。

另在服务器内部读取 5 个现用秘密配置值，对当前远端全部历史的 636 个 blob 做精确比对，未发现匹配；这些值未输出到终端、报告或 Git。本次扫描不能确认已经被删除且不再可达的对象、其他仓库、历史 fork 或第三方留存中的内容。若其他渠道曾泄露凭据，仍应在对应供应商撤销。

已补齐 `.runtime/`、各类私有 `.env`、`*.env`、私钥与证书包的忽略规则，保留可发布的 `.env.example`。新增回归检查验证这一边界。服务示例默认只监听 `127.0.0.1`，避免首次启动直接暴露到局域网。

认证、角色、跨组织访问、只读 Demo、试用账号和 API Key 隐藏沿用后端校验；现有 HTTP 安全回归与 MCP 测试已通过。模型没有获得额外工具或批准通知的权限。

公告与复核依据：[proxy-addr](https://github.com/advisories/GHSA-jqcg-44mw-7w3h)、[MCP SDK](https://github.com/advisories/GHSA-6qxp-vccf-f47h)、[sprintf-js](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。完整依赖审计在本机私有检查记录中保留，未将生产配置附入报告。
